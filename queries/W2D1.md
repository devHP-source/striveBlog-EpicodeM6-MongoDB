# W2D1 - Queries in MongoDB Compass

## Import the sample collection

1. In MongoDB Compass, connect to the cluster and create the database `M6-W2D1` with the collection `users`.
2. Open `users` and click **Add Data → Import JSON or CSV file**.
3. Select `W2-P1-database-di-prova-per-MongoCompass.json` and click **Import**. The collection now has 97 documents.

## Queries

Each filter goes in the **Filter** bar of the `users` collection. The projection of query 7 goes in **Project**, under **Options**.

In the sample data the eye color field is `eyeColor` (not `eyes`).

| # | Request | Filter | Project | Found |
|---|---|---|---|---|
| 1 | `isActive` is `true` | `{ isActive: true }` | | 51 |
| 2 | `age` greater than 26 | `{ age: { $gt: 26 } }` | | 54 |
| 3 | `age` greater than 26 and less than or equal to 30 | `{ age: { $gt: 26, $lte: 30 } }` | | 19 |
| 4 | eyes "brown" or "blue" | `{ eyeColor: { $in: ["brown", "blue"] } }` | | 66 |
| 5 | eyes not "green" | `{ eyeColor: { $ne: "green" } }` | | 66 |
| 6 | eyes neither "green" nor "blue" | `{ eyeColor: { $nin: ["green", "blue"] } }` | | 35 |
| 7 | `company` is "FITCORE", only the email | `{ company: "FITCORE" }` | `{ email: 1, _id: 0 }` | 1 |

Result of query 7: `victoria.solis@fitcore.biz`

## Notes

- Queries 4 and 5 find the same documents because the only eye colors in the data are green, blue and brown.
- In query 7, `_id: 0` hides the `_id`, which Compass would otherwise show next to the email.
